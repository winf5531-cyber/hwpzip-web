한글 파일을 5MB·15MB 미만으로 줄이는 방법

사진을 붙인 보고서가 첨부 용량을 넘었다면 제출처의 제한부터 확인하세요. 15MB까지 받는 곳이라면 15MB 미만을 선택하세요. 한도가 5MB일 때는 같은 원본에서 5MB 미만으로 다시 시작하면 됩니다.

사진이 많은 한글 파일 압축하기

  1. 한글 압축 도구에서 원본 HWP 또는 HWPX 파일을 선택하세요.
  2. ‘첨부용 압축’을 선택하고 목표 용량을 고른 뒤 ‘용량 줄이기’를 누르세요. 문서에서 용량이 큰 사진부터 줄이고 목표 미만이 되면 멈춥니다. 표 셀의 배경으로 채운 사진도 검사합니다.
  3. 결과 화면에서 실제 용량을 확인하고 새 파일로 저장하세요. 본문 글자는 그대로지만 스캔한 증빙 속 작은 숫자와 도장은 이미지의 일부이므로 확대해서 확인하세요.

42.23MB 문서에서 사진을 몇 장 줄였을까요?

같은 HWPX 원본을 두 번 압축했습니다. 15MB 목표에서는 큰 사진 한 장만 바꿔도 충분했습니다. 5MB 목표에서는 두 장을 바꿨습니다.

스캔한 글자나 도표가 많다면

작은 글씨의 선 하나까지 보존해야 하면 원본에서 ‘무손실 압축’를 선택하세요. 이 방식은 이미지 픽셀을 바꾸지 않습니다. 이미 압축한 사진이 많거나 사진 외의 내용이 용량의 대부분이면 줄어드는 용량이 작을 수 있습니다. 이때는 결과 크기를 확인하고 제출처가 허용하는 경우 문서를 나누어 첨부하세요.
